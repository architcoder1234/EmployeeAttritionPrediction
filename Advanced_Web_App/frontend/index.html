📊 Model Insights

        
Why Logistic Regression was chosen over Decision Tree, Random Forest, and XGBoost.

      


      

        
Model comparison

        

        

        

          Models within 0.02 F1-score of each other are treated as "practically tied," and the
          tie is broken using ROC-AUC. Decision Tree edges out Logistic Regression on raw F1
          (0.517 vs 0.507), but Logistic Regression's ROC-AUC (0.807) is well ahead of Decision
          Tree's (0.736) — making it the more reliable choice for deployment.

ℹ️ About this Project

      

      

        
Employee Attrition Prediction System

        
AIML Summer Internship 2026 — IIHMF, MNNIT Allahabad
Capstone Project 4

        
This tool predicts whether an employee is likely to leave an organization, using
        historical HR data and a Logistic Regression model chosen for its strong recall and
        ROC-AUC rather than raw accuracy alone.

        
Pipeline: data cleaning → EDA → feature engineering (TenureRatio,
        IncomePerYearExp, PromotionGap, AvgSatisfaction) → SMOTE balancing → model comparison
        (Logistic Regression, Decision Tree, Random Forest, XGBoost) → deployment.

        
Author: Archit — B.Tech CSE, United College of Engineering &
        Research (UCER), Prayagraj

        
This custom frontend calls a FastAPI backend wrapping the same
        trained model used in the Streamlit deployment — both stay in sync via a single
        shared prediction module.
